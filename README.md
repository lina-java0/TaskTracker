Task Tracker — backend-приложение для управления задачами.

Реализовано:

- REST API для создания, просмотра и удаления задач;
- хранение данных в базе данных с использованием Spring Data JPA;
- разделение приложения на controller, service и repository слои;
- тестирование API через Postman.

Проект находится в разработке. Планируется расширение модели задачи и добавление веб-интерфейса для работы с приложением.
